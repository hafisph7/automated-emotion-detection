# Automated Emotion Detection Using Text and Feedback

## Project Description
This project implements an automated emotion detection system using Natural Language Processing (NLP) and a BERT-based transformer model. The system classifies emotions from textual input and provides real-time predictions through a Streamlit web application.

## Technologies Used
- Python
- BERT (Hugging Face Transformers)
- PyTorch
- Streamlit
- Google Colab
- Kaggle Emotion Dataset

## Emotion Classes
- Joy
- Sadness
- Anger
- Fear
- Love
- Surprise

## Dataset
The dataset consists of three CSV files:
- training.csv
- validation.csv
- test.csv

These files are stored in the `dataset` folder.
